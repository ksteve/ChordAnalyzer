# Chord Analyzer

A simple, clean tool to help you learn piano chords, scales, and how notes fit together.

**Live demo:** https://ksteve.github.io/ChordAnalyzer/

## Goal

Play notes and instantly see:
- Which chord you're playing
- Whether it belongs to the selected key/scale
- The Roman numeral (I, ii, V, etc.)
- The notes of the current scale

This helps you understand relationships between notes, chords, and scales without clutter.

## How to use

1. **Choose a key** from the dropdown (e.g. C major, A minor).
2. **Play notes** using any of these methods:
   - **MIDI keyboard** (if connected)
   - **Computer keys**:  
     `A W S E D F T G Y H U J K`  (white and black keys starting from C)
   - **Mouse / touch**: click or tap the piano keys
3. Watch the chord name, color (green = in the key, red = outside), and Roman numeral update in real time.
4. The last few stable chords are saved in the history bar so you can review progressions.

## Learning tips

- Start in **C major**. Play only white keys and notice how many common chords light up green.
- Try building triads: root + 3rd + 5th (skip one white key each time).
- Switch to a minor key and hear the different flavor of the same shapes.
- Watch the scale notes listed under the key selector — those are the “safe” notes for that key.

Keep it simple. Play, listen, look. That’s how the relationships stick.
